# Moodle Local Course Image

Allow teachers to update a course image without granting permission to edit the course summary. The teacher will a "Course image" option in the "More" menu.

## Overview

In Moodle, course images are stored in the course **Overview Files** area and are normally managed through the Course Settings page.

Unfortunately, restricting the capability prevents teachers from editing both: Course Summary and Course Image

This plugin alllow teachers to update only the course image.

## Requirements
Moodle 4.5+

## Instalation
Download and copy the file to local/courseimage

## Capabilities

**local/courseimage:manage**

Allows a user to manage course images.

Default assignments:

| Role | Permission | 
|------|------------|
| Manager | Allow |
| Editing Teacher | Allow |
